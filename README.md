# Runyi Zheng — portfolio

纯静态网站（HTML + CSS），没有需要安装的东西。

## 发布到 GitHub Pages
1. 新建公开仓库，名字必须是 `crystalove08.github.io`
2. 把这个文件夹里的所有文件（包括 `assets` 文件夹和隐藏文件 `.nojekyll`）上传到仓库根目录
3. Settings → Pages → Branch 选 `main` / root → Save
4. 几分钟后访问 https://crystalove08.github.io

## 添加图片作品
每个案例页最下面有一个 "Selected work" 图片区，灰色框里写着要放的路径。
把图片放进对应文件夹，命名为 `01.jpg`、`02.jpg`……（也支持 png、jpeg、webp），刷新页面就会出现。

| 案例 | 文件夹 | 位置数量 |
| --- | --- | --- |
| Paid Media Performance Diagnosis | `assets/paid-media-diagnosis/` | 3 |
| Fall Collection Sale | `assets/fall-collection-sale/` | 6 |
| Social Media Content | `assets/social-content/` | 9（竖图 4:5） |
| Blog Writing | `assets/blog-writing/` | 3 |
| ClosetMate | `assets/closetmate/` | 3 |
| Campus Free Printing | `assets/campus-free-printing/` | 3 |

发布前，没有放图片的灰色框会一直显示，不想要的话告诉我，我帮你删掉多余的位置。

## 软件 logo
放进 `assets/logos/`，文件名：`sql`、`r`、`stata`、`google-analytics`、`google-ads`、`meta-ads`、`pinterest-ads`、`canva`、`capcut`、`photoshop`、`excel`、`sawtooth`、`survey-design`（svg、png 或 webp）。没放的只显示软件名字。

## 修改文字
用文本编辑器打开对应的 html 文件，直接改里面的英文：
`index.html`（首页、About、Experience、Skills、Contact）和六个案例页。
